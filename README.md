# Volabyte

Volabyte is a simple, fast, and secure file storage solution for your personal or team projects.

## Disclaimer

- ⚠️ The project is under active development.
- ⚠️ We do our best to ensure a reliable upgrade path, but we cannot guarantee that there will be no issues during upgrades.
- ⚠️ Always follow [3-2-1](https://www.backblaze.com/blog/the-3-2-1-backup-strategy/) backup plan for your data.
